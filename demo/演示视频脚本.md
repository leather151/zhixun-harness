# 运行演示视频 · 分镜脚本（≤ 5 分钟）

> 一键执行：`.\demo\run_demo.ps1`（无网络时加 `-Offline`，策略回落规则版）
> 实测：`-SkipLoop` 17 秒；完整演示约 2 分钟 —— 5 分钟上限绰绰有余。
> 全部本机真实运行，不预录、不造数字。

## 一、这次演示覆盖的三个规则要求

| 规则要求 | 演示里怎么体现 | 节 |
| --- | --- | --- |
| 驱动 Harness 的大模型必须是 PyTRiO 训练的模型**或 Qwen3.8-27B** | 闭环用 `--policy llm`，走 PyTRiO `Qwen/Qwen3.8-27B`；每窗打印 `source=llm`、3/3 票一致、token 用量；另展示我们在 PyTRiO 上 LoRA 微调的决策模型权重路径 | 2、6 |
| **三轮独立**"读历史 → 做实验 → 依据结果决策" | 三个不同假设 → 改配方真训（官方 `python -m baselines.train`）→ 按公开验证集采纳/驳回 | 3 |
| **评测数据包可能不是这三个旧数据集** | 现场造一个 7 维全新 schema 的数据包 → 训练（自动切换自适应通道）→ 按 schema 找模型预测 | 4 |

> 注意：第 2 节的 LLM 决策需要网络（PyTRiO）。**离线评测环境会自动回落规则版**，
> 所以录不到 LLM 时用 `-Offline`，并在解说里说明"封闭环境无外网 → 规则兜底"。

## 三、逐节命令（手敲用）

```powershell
cd D:\pycharm\competition
$env:PYTHONPATH = (Get-Location).Path

# 1 自检
$env:HARNESS_MODE = "selftest"; python -u harness/entry.py

# 2 闭环（Qwen3.8-27B 决策）
$env:HARNESS_MODE = "loop"
python -u harness/entry.py --task B --stream train --windows 4 --policy llm --swan off --out $env:TEMP\demo-runs

# 3 三轮独立实验
python demo/round_protocol_sim.py --task A --rounds 3 --engine experiment

# 4 新数据包
python demo/make_new_package.py
python -m baselines.train --profile A --train $env:TEMP\newpkg\train.jsonl --validation $env:TEMP\newpkg\validation.jsonl --output $env:TEMP\newpkg\round-1 --epochs 20 --json
$env:HARNESS_MODELS = "$env:TEMP\newpkg"
python -c "import sys,json;sys.path.insert(0,'.');from baselines.predict import predict_auto;print(predict_auto(json.loads(open(r'$env:TEMP\newpkg\validation.jsonl',encoding='utf-8').readline())['inputs']))"
```

## 四、必须说清的三句话

1. **验证集只测不改**：`--stream official` 会强制 `updates_allowed=False`。
2. **选型只用 train 内部留出**：B 按整根轴承留出，A 按类别分层切时间尾部。
3. **交的是系统，不是一个模型**：每轮都有监测/归因/决策/守门/回滚的完整证据链。
