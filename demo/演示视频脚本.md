## 三、逐节命令（对不上画面时手敲用）

```powershell
cd D:\pycharm\competition

# 0/1 自检
$env:HARNESS_MODE = "selftest"; python -u harness/entry.py

# 2 闭环（4 窗口，B 包）
$env:HARNESS_MODE = "loop"
python -u harness/entry.py --task B --stream train --windows 4 --policy auto --swan off --out $env:TEMP\demo-runs

# 3 平台协议本地复刻
python demo/round_protocol_sim.py --task A --rounds 3 --windows 2

# 4 预测协议
$env:HARNESS_MODE = "serve"
Get-Content "D:\人工智能大赛\02_数据\B_滚动轴承RUL\validation.jsonl" -TotalCount 1 | python -u harness/entry.py --echo-task

# 5 记录
Get-Content runs\trio_sft_report.json -Raw
```

## 四、必须说清的三句话（评审关注点）

1. **验证集只测不改**：`--stream official` 会强制禁用一切更新，代码里有 `updates_allowed=False` 的硬开关。
2. **选型只用 train 内部留出**：B 按整根轴承留出，A 按类别分层时间尾部，从未用官方 validation 调参。
3. **不是"一个更准的模型"，而是"能自己维持和提升的系统"**：闭环每轮都在监测→归因→决策→守门→回滚，产物自带完整审计字段。

## 五、万一现场出问题

| 情况 | 处理 |
| --- | --- |
| 终端卡顿/耗时超预期 | `.\demo\run_demo.ps1 -SkipLoop`（跳过闭环，约 20 秒） |
| 数据路径不在 `D:\人工智能大赛` | 设 `HARNESS_DATA` 指向含 `A_气体传感器/` 的目录 |
| SwanLab 打不开 | 提前截图保存，播放截图 |
| 平台报告页打不开 | 用 `提交材料/合规自查与试运行解读.md` 里的结果表代替 |
