## 一、开源组件声明

| 组件 | 用途 | 许可证 | 是否入镜像 |
| --- | --- | --- | --- |
| Python 3.12-slim（官方 base image） | 运行时 | PSF / Debian 各组件许可 | ✅ |
| NumPy 1.26.4 | 全部数值计算（训练/推理/指标） | BSD-3-Clause | ✅ |
| 赛题方提供的 CPU 基线代码（`vendor/`、`baselines/`） | 工业模型与训练入口 | 随赛题数据包分发，**版权归赛题方** | ✅（原样保留，改动处已注明） |
| PyTRiO Python SDK（`pytrio`） | **仅本地开发**用于 LoRA 微调与权重导出 | 见其官方许可 | ❌ **不入镜像** |
| SwanLab（`swanlab`） | 云端实验记录 | Apache-2.0 | ❌ 不入镜像（评测环境断网） |
| 平台 PyTRiO 模型服务（Qwen3.8-27B） | 评测期 Harness 驱动模型 | 由平台提供 | ❌ 通过平台注入访问 |

**本仓库自研部分**：`harness/`（闭环、策略、指标、漂移、交付、日志）、`baselines/train.py`
的配方注入层、`demo/`、`tests/`。全部原创，未拷贝第三方闭环实现。

> 对赛题方代码的改动只有一处功能性补丁：`vendor/{A,B}/model.py` 的 `fit()` 增加**可选**
> `sample_weight` / `weight_decay` 参数，默认值下与官方实现逐位一致（已用 `657.65 / 880 步`
> 的固定样例核对过）。C 包未改动。

## 二、模型声明

| 模型 | 来源 | 说明 |
| --- | --- | --- |
| 工业模型（A/B/C） | 赛题方 CPU 基线 `contest.cpu-mlp.v1`（单隐层 tanh MLP，参数量 833–4,609）<br>由本系统自迭代产出 | 参数上限 100,000 已满足；未引入任何外部预训练权重 |
| Harness 驱动模型（路线一） | **PyTRiO 指定的 `Qwen/Qwen3.8-27B`** | 评测环境由平台注入接入信息；不可用时降级 `Qwen/Qwen3.5-4B`，再无则确定性规则版 |
| Harness 驱动模型（路线二，自训） | **我们在 PyTRiO 上 LoRA 微调的决策模型** | 基座 `Qwen/Qwen3.5-4B`，LoRA rank 32，44 步，loss 3.11→0.03；权重路径 `trio://run_4e2okzovpr66/sampler_weights/zhixun-policy-v2`；语料为 57 次真实闭环运行的 87 条决策轨迹 |

- **未使用**任何未授权的模型或 API：镜像内不含任何大模型权重、不含密钥，评测期只访问平台提供的 PyTRiO 服务。
- 决策留痕：每窗位置记录 `source`（`llm` / `rule` / `rule(fallback)`）与 `model_used`，可逐条自证用了哪个模型。

## 三、数据声明

| 项 | 说明 |
| --- | --- |
| 使用的数据 | **仅**赛题方公开数据包：UCI Gas Sensor Array Drift（气体六分类）、XJTU-SY（轴承 RUL）、NASA C-MAPSS（涡扇 RUL） |
| 隐藏测试集 | **从未接触**；本仓库不含任何隐藏样本、名单或标签（规则明确禁止获取） |
| 外部数据 | **未使用**任何外部数据集或预训练语料 |
| 数据划分 | `public/train.jsonl` 只用于梯度更新；`public/validation.jsonl` **只测不改**（`--stream official` 下强制 `updates_allowed=False`） |
| 统计量拟合 | 标准化均值/方差、ECDF 分位表**只在 train 上拟合**，随检查点保存；验证集不参与 |
| 标签 | **未合成任何标签**：不做 RUL 封顶、不做健康等级分箱；蒸馏时的"标签"来自我们自己的模型输出，且已明确标注为蒸馏 |
| 输入安全 | `id` / `meta` 不作为模型输入，防止泄漏目标信息 |

## 四、安全与受控机制

| 要求 | 实现 |
| --- | --- |
| 防止无限制恶意迭代 | `harness/config.json` 四道硬上限：`max_updates=4`、`max_epochs=8`、`max_seconds=600`、`max_windows=12`；触发即停并写 `events` |
| 禁止未授权外网访问 | 镜像内默认无任何外联；只使用平台注入的 PyTRiO 端点；SwanLab 在容器内关闭 |
| 无恶意代码 | 全部源码可审阅；无动态下载、无 shell 调用外部程序、无遥测；以非 root 用户 `runner(10001)` 运行 |
| 账号与密钥 | 账号未转借；API Key 只存在于本机 `.env.local`（已 `.gitignore`），**不入镜像、不入仓库** |
| 可追溯 | 每轮产物含 `windows.jsonl` / `decisions.jsonl` / `experiments.jsonl` / `manifest.json`（sha256、父检查点、指标序列、成本） |
